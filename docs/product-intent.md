# Product Intent

## The problem

Modern Macs run dozens of background processes that make network connections: browsers, chat apps, cloud sync, update checkers, telemetry, MCP servers, local AI tools. There is no simple way to know whether all of this is expected or whether something is quietly phoning home.

Existing tools either show raw packet data (unusable for non-engineers) or cost money and require complex configuration (Little Snitch). There is nothing that answers the simple question: "Is anything unexpected happening on my network right now?"

## The product promise

Open Netwatch. See immediately whether all connections are expected, whether anything new appeared, and whether anything violates rules you set. Form a judgment in seconds, not minutes.

## Target behavior change

Before Netwatch: network activity is invisible. Trust is assumed. Problems are discovered only after something goes wrong.

After Netwatch: network activity is visible and classified. Trust is verified. Unexpected behavior is surfaced the moment it happens.

## Success criteria

- The user opens the app voluntarily (not reminded) at least 3 times per week
- The user can distinguish expected from unexpected connections within 5 seconds of opening
- The user's trust database grows organically from real usage
